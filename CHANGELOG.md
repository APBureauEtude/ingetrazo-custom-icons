# Changelog

## 1.1 — 2026-10-15

- The pairing by file name uses IngeTrazo's own names, those of
  «Icônes originales»: `line.svg` replaces the Line icon, and
  `cursors/line.svg` the Line tool's cursor (see NAMES.md). A theme made
  from copies of the originals is paired on its own. Themes already
  paired on the page keep their pairing.
- Where a cursor clicks depends on the tool it serves, not on its file's
  name. A tool without a pointing drawing clicks where IngeTrazo's own
  cursor does.

## 1.0.1 — 2026-10-14

- The library showed only the icons at the root of the theme's folder
  when the page opened (the folder filter started on that folder instead
  of «All folders»).

## 1.0 — 2026-10-11

First release.

- Replaces IngeTrazo's toolbar icons and the 3D view's cursors with SVG
  files, live, with no restart.
- Icon themes: one folder each in «Icônes custom», with its own pairing,
  saves and imports; a theme is shared by sharing its folder.
- A page in the browser (Extensions ▸ Custom icons ▸ Choose icons…) to
  pair icons by dragging or by two clicks, choose the theme, save and load
  pairings, pick icons from another theme or import SVG files; in French,
  English or Spanish.
- Pairing by file name until a theme's first change (see NAMES.md).
- A cursor's hotspot is found in its drawing.
- The original icons written as SVG files, as a reference and a template.
